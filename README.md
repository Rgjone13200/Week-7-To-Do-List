This project is a simple, interactive To-Do List Application created using HTML, CSS, and JavaScript. The purpose of this assignment is to demonstrate basic web development skills, including DOM manipulation, event handling, functions, and user interface design.

The application allows users to create, manage, edit, complete, and delete daily tasks through an easy-to-use interface.

Features

Add Tasks: Users can enter new tasks and add them by clicking the Add Task button or pressing Enter.

Display Tasks: All added tasks appear in a list on the webpage.

Complete Tasks: Users can click a task or the Complete button to mark it as finished.

Delete Tasks: Users can remove tasks using the Delete button.

Edit Tasks: Users can modify existing tasks.

Save Tasks: Tasks are saved using the browser's localStorage, allowing them to remain available after refreshing the page.
